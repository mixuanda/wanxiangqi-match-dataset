# 覆盖与研究路线图

长期目标是在合规和隐私可控前提下，逐步扩大对高段位公开对局的覆盖。不能承诺一定获得全部，也不能用单一入口样本冒充高段位全覆盖。

| 阶段 | 工作 | 进入下一步的依据 |
|---|---|---|
| 当前：方法与合成契约 | 字段字典、允许清单、清洗器、拒绝测试、质量与隐私说明 | 代码和合成样例可复现；真实记录不公开 |
| 来源与访问条件审查 | 识别允许使用的公开来源、保留条款/授权依据，验证段位与模式定义 | 使用及再分发范围明确；可记录来源但不泄漏私人信息 |
| 覆盖审计 | 分段位、时间桶、模式与版本记录候选/成功/失败/去重情况 | 明确每项分母、未知项和访问缺口 |
| 扩展授权样本 | 在允许范围逐步增加不同来源玩家，验证跨查看者对局身份 | 不绕过登录、访问限制、反作弊或平台保护；不把昵称当身份 |
| 聚合研究 | 模式分层、阶段阵容、等级轨迹及缺失敏感性分析 | 说明聚合阈值与再识别风险，排除决策泄漏 |
| 独立发布评审 | 确认权利、必要性、最小化和删除/纠错机制 | 单独批准；未满足就继续只公开方法与合成样例 |

访问治理要求：尊重平台访问范围和限速；遇到限制采用退避、保守冷却和停止条件，不绕过封禁，不自动重试至成功。只在明确授权、单一采集协调者和可审计预算下考虑未来采集。本仓库没有在线采集器，也没有后台轮询或定时任务。

策略研究需要额外的决策时点上下文；即使扩大对局数量，也不会自动补全商店备选、动作成本、手牌或点击回执。后续若做效果评估，应预注册对照与独立样本，不能把描述性频率当提高胜率的证明。

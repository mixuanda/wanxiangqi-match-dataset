# 质量说明

## 数据粒度与分母

对局、参赛观察、阶段和棋子快照是不同粒度。同局参赛者的结果相互相关，阶段也重复观察同一对象。描述某个来源角色的阵容频率时，以每局该角色一条观察为分母，不把全部参赛者当作更多独立玩家。

## 必须分开的信息

- 不同模式分别统计。资源量级、阶段结构、起始等级可能不同。
- 版本/补丁与源显示时间时区未知时保持未知；按日期分组不等于按补丁分组。
- 最终阵容与逐阶段棋盘分开。只看终局会漏掉过渡角色。
- 卡牌计数汇总与输入动作分开。获得不等于购买，移除不等于出售。
- 来源对局标识的跨查看者唯一性未验证时，不宣称完成跨玩家去重。

## 当前私有样本的限制

当前结构核验基于单一入口来源的476场，而非覆盖所有段位的随机样本。成功取回详情的子集可能偏向较新或更容易访问的条目；未取回项不是随机缺失的保证。没有可靠的高段位标签、完整版本信息或决策前输入上下文。真实逐条记录及精确时间不在公开仓库中。

## 学习和效果评估

如未来开展授权研究，同一局的所有查看者、参赛者、阶段、棋子与卡牌摘要必须归入同一集合；再按有证据支持的时间分组。未知或冲突时间隔离。只在训练集合拟合统计变换，探索过的留出数据不能继续宣称为盲测。

最终名次、最终阵容、未来阶段、当前动作之后的资源以及未侦察的赛后对手棋盘，都不能进入对应时点的决策特征。存活更久会同时影响最终等级和结果，因此终局相关性不是升级策略的因果效果。

本版只验证结构、清洗边界与合成示例，不训练模型，也不提供策略有效性评分。未知数据不得填0、伪造动作或补出报价。
